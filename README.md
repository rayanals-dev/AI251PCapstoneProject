# Project: Cross-Domain Aerial Detection and Segmentation: From Maritime to Urban, Desert and Mountain Environments

## Summary: 
This project detects, classifies and segments small objects (vessels, swimmers and vehicles) in aerial imagery, and measures how well one model transfers from the sea to land, desert and Saudi mountain scenes. It reports, for each environment, whether the model is accurate enough to deploy. Final decisions always remain with a human operator.

## System Overview:
Input: Images or video frames recorded from an aerial or elevated viewpoint (UAV or high vantage point) over water, cities, desert or mountain roads.
Output: Detected objects with class, confidence, bounding box, mask and estimated object size, shown on annotated imagery for human confirmation.
